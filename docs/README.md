# Engineering documentation

This directory contains Drever's implementation contracts, architectural
decisions, contributor references, and release procedures. It is written for
maintainers and contributors who need to understand how the framework works and
which invariants a change must preserve.

The canonical public user guides are authored in
[`website/content/docs`](../website/content/docs/) and published at
[drever.dev/docs](https://drever.dev/docs/). Keep task-oriented onboarding and
user-facing product guidance there. Keep implementation rationale, internal
boundaries, and contributor procedures here.

[`quickstart.md`](./quickstart.md) is a detailed repository reference for
validating the complete delivery surface. It does not replace the shorter,
task-oriented public guides.
