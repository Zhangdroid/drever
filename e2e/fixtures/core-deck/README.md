# Core browser fixture

This private deck is the stable authored input for Drever's audience, speaker,
document, export, Stage, Step, React-state, and motion-contract E2E tests.

It is deliberately not a public example or design showcase. Tests should prefer
semantic attributes, accessible roles, routes, and the explicit geometry in
`fixture.css`; do not turn its prose, palette, or composition into additional
product contracts. Public examples are validated by source checks and website
builds so their narrative and design can evolve independently.
