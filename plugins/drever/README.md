# @drever/agent

The installable Drever agent plugin for Codex and Claude Code. It provides five
workflows that create a deck, derive subject-led art direction, author focused
changes, review presentation readiness, and deliver AI-first MDX presentations.

The global plugin can start from an empty directory with
`npm create drever@latest`. After creation it delegates to the project-local
agent kit generated by that exact Drever version, so existing projects never
silently switch to `drever@latest`.

This package contains no hooks, MCP server, model SDK, or runtime dependency.
Agents use the project's normal file tools and local Drever CLI, which keeps
permissions, diffs, validation, and delivery visible.

The checked-in plugin skills are generated byte-for-byte from
`packages/cli/agent-kit/skills`. They remain regular files because package and
plugin installers do not reliably preserve symbolic links. Run
`vp run -F @drever/agent sync` after editing the canonical skills and
`vp run -F @drever/agent test` to detect any missing, changed, extra, or
symbolic generated file.
