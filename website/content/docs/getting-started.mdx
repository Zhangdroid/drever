<h2 id="what-the-agent-does">What the handoff completes</h2>

1. **Prepare** — creates a safe project and installs its version-matched Codex and Claude Code
   workflows.
2. **Create** — turns the brief into readable MDX, speaker notes, a topic-specific visual system,
   and intentional motion.
3. **Review** — checks the source, builds the static presentation, and inspects the rendered states
   when browser tools are available.

The public [`prompt.md`](/prompt.md) only starts the work. Once the project exists, its local
instructions and skills take over so the agent always follows the contract for the installed Drever
version.

When the brief is incomplete, the agent can ask a few adaptive rounds and always offers **Skip
remaining questions — surprise me**. It collects only missing choices that materially affect the
result, such as duration, audience outcome, slide density versus speaker notes, motion intensity,
and topic-specific priorities. Selecting surprise mode ends the interview immediately.

The work happens in ordinary files on your machine. Setup succeeds when the agent leaves a running
local preview, a readable `slides.mdx`, and the requested web or PDF outputs ready for review.

<h2 id="local-workflow">Know what runs where</h2>

The website button copies text; it does not upload the brief or start a hosted generation job. Paste
the prompt into the coding agent you already trust. That agent creates a local React and MDX
project, installs packages from npm, and may use the network for research only when the brief and
your agent permissions allow it.

Drever does not add telemetry to the generated project. Your chosen AI provider, any remote media,
and the platform where you later publish the static build each keep their own privacy contract.

<h2 id="write-a-useful-brief">Give the agent a useful outcome</h2>

A single sentence is enough to begin. Include the audience, the change you want, and any required
source material when you know them:

> Create a short presentation for local residents about three proposals for a shared public space.
> Help them understand the trade-offs and decide which proposal to support. Use the planning brief
> and survey results as source material.

The agent can infer ordinary details and state its assumptions. Choose surprise mode at any point
to let it resolve every remaining choice, or keep answering while the questions are useful.
