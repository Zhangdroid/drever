<h2 id="what-the-agent-does">What the handoff completes</h2>

1. **Prepare** — creates a safe project and installs its version-matched Codex and Claude Code
   workflows.
2. **Create** — turns the brief into readable MDX, speaker notes, a topic-specific visual system,
   and intentional motion.
3. **Review** — checks the source, builds the static presentation, and inspects the rendered states
   when browser tools are available.

The public [`prompt.md`](/prompt.md) only starts the work. Once the project exists, its local
instructions and skills take over so the agent always follows the contract for the installed Drever
version.

<h2 id="write-a-useful-brief">Give the agent a useful outcome</h2>

A single sentence is enough to begin. Include the audience, the change you want, and any required
source material when you know them:

> Create a 10-minute update for frontend teams about React 19. Help them decide which features to
> adopt now. Use current official React sources for the facts and visual direction, then deliver a
> live deck and PDF.

The agent can infer ordinary details and state its assumptions. It should ask only when missing
facts or a real decision would materially change the result.
