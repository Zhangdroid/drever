# Bus-priority decision lab

A hidden, 15-slide forward-generation experiment for a fictional city-council
decision on a six-month bus-priority-lane pilot. A clean consumer installed
candidate `0.0.0-commit.g686632e6eef2`, then a fresh Codex session authored,
reviewed, and repaired the deck from the approved evidence-bounded brief.

The lab keeps the brief, Storyboard contract, art direction, authored source,
and local design system as reproducible evidence for Drever's generation
guidance. It is built for a direct review URL but is intentionally absent from
the public showcase and search index.
