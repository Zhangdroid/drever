# Seasons generation lab

A hidden, 15-slide forward-generation experiment explaining why Earth's
seasons are caused by axial tilt rather than orbital distance. A clean consumer
installed candidate `0.0.0-commit.g686632e6eef2`, then a fresh Codex session
authored and refined this deck from the approved brief.

The lab preserves its brief, Storyboard contract, art direction, authored
source, and local design system so changes to Drever's generation guidance can
be compared against a real long-form result. It is built for a direct review
URL but is intentionally absent from the public showcase and search index.
