# Airport-wayfinding generation lab

A hidden, 15-slide forward-generation experiment translating airport
wayfinding into practical interface principles for product teams. A clean
consumer installed candidate `0.0.0-commit.g686632e6eef2`, then a fresh Codex
session authored and repeatedly refined the deck from the approved brief.

The lab retains the brief, Storyboard contract, art direction, authored source,
and local design system so Drever's generation and transition guidance can be
evaluated against a real long-form result. It is built for a direct review URL
but is intentionally absent from the public showcase and search index.
